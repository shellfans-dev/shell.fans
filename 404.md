## How to find a valid URL

- **[sitemap.xml](https://shell.fans/sitemap.xml)** — every indexable URL. If a
  path is not listed there, it does not exist. Check here before retrying.
- **[llms.txt](https://shell.fans/llms.txt)** — what ShellFans is, what it does,
  and when an agent should use it.
- **[llms-full.txt](https://shell.fans/llms-full.txt)** — the same, expanded.
- **[developers](https://shell.fans/developers)** — the public machine-readable
  surface: which endpoints exist, which do not, and why.
- **[openapi.json](https://shell.fans/openapi.json)** — OpenAPI 3.1 description
  of the public read-only endpoints.

## Content negotiation

Public informational pages return Markdown when the request carries
`Accept: text/markdown`. The URL is unchanged — only the representation differs.
The HTML form remains canonical.

## Write operations

`shell.fans` exposes no public write API. `POST`, `PUT`, `PATCH` and `DELETE`
will not succeed on any path. Do not retry them.
